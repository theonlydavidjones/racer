# Badges that follow the real ladder (Debrief, 13 Nov 2026)

**Decided (the owner, via the Coordinator, 13 Nov):** ASA. The badge reads "101 · Basic Keelboat skills". Its hover says "Practice of the ASA 101 skills in the sim. Not the ASA certification." Before the badge ships (PR 6), the 12 lessons get checked against ASA 101's own published standard. The permission flag below still holds.

The owner: "Badges should follow normal sailing certifications. ASA 101, etc." The picture is `badges-mockup.png`.

- **The mapping.** Each course set in the sim practices one real certification's skills:
  - Learn to sail (12 lessons) = 101 Basic Keelboat;
  - a coastal cruising set = 103;
  - bareboat = 104;
  - navigation = 105.
  Racing has no ASA course, and only a US Sailing one sourced from a school page (109, Performance Race Week), so the racing set keeps the sim's own name.
- **The badge reads** "101 · Basic Keelboat skills". One hover says "Practice of the ASA 101 skills in the sim. Not the ASA certification." (or US Sailing's, by the owner's pick). There is no other copy.
- **Which ladder?** Most Bay schools teach ASA: Modern Sailing, Tradewinds, SailTime, Spinnaker. OCSC teaches US Sailing, and Club Nautique, which taught US Sailing, closed at the end of 2025 (Modern Sailing's own page says so). Both ladders number 101 / 103 / 104 / 105 alike, so the badge reads the same either way.
  - The lessons were built on US Sailing's Basic Keelboat standard, which is published. ASA 101's standard couldn't be read this session (its sites didn't resolve), so if ASA is chosen, check the lessons against its text first.
- **⚠ Permission before any public release.**
  - US Sailing: "US SAILING" is a registered mark. Its branding page asks instruction organizations for written approval before using the logo (https://www.ussailing.org/branding/).
  - ASA: "ASA" and "ASA American Sailing Association" are registered marks (USPTO listings via trademark.justia.com).
  - This is the same rule we have for club names and burgees.
