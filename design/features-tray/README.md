# The features tray (mock-up for the owner; nothing built)

The owner, 15 Nov 2026: "there's a lot of really cool shit we've built, like wind-in-air and wind-over-sails, but it's hard
to find these things. I think we need a 'more' (not that copy though) button on the game surface for all features that
show up on the game surface itself."

Stills, drawn over the real page (`mock.cjs`):
- `1-closed.jpg`: the top bar. **Show** takes Speed's place.
- `2-open.jpg`: the tray open.
- `3-tile-on.jpg`: a tile on (wind in the air, live in the scene).

## The button
- One icon button in the top bar, a 2×2 grid icon labeled **Show** (the bar's buttons all carry a word).
- It takes **Speed's** slot. Speed moves into the tray as its last row, as the screen audit (Crew Art) asked: "Real racing is
  at 1×". So the bar keeps four buttons.

## The tray
- It drops from the button. Each tile is an icon and a name, with its key in the corner (rebindable in Keys, as now).
- **A lit tile is on** (teal, the coach's target color). A dashed tile is an action, not a switch (Hail, Paddle).
- The tiles: Wind in the air · Flow over the sails · Points of sail · Sail band · Course chart · Cabin-top instrument ·
  Nav lights · Paddle · Hail · Log · Frame readout; then Speed 1× / 2× / 4×.
- It closes on Show, Esc or a click outside, like the other overlays.

## What it absorbs
- **Speed** leaves the bar.
- **The flow button** (#375, in the band's tab row) isn't needed there: Flow over the sails is a tile.
- **The View button** (bottom right) stays. The audit keeps it, and it cycles three views on one press.

So the surface ends one button lighter (the flow button), with every surface feature one click away.

## For the owner
- The word on the button: **Show**, or no word at all (the icon alone)?
- Whether Hail and Paddle belong here: both are actions, with their own keys and, for Hail, the band's tab.
